# Testes de Software com Java e JUnit

Repositório desenvolvido durante meus estudos de **Testes de Software**, com foco na prática de **testes unitários em Java utilizando JUnit 4 e Hamcrest**.

O objetivo deste projeto foi compreender, na prática, como criar testes automatizados para verificar o comportamento de funcionalidades de uma aplicação e aumentar a confiabilidade do código.

## Objetivos do estudo

Durante o desenvolvimento deste projeto, pratiquei conceitos como:

* Testes unitários
* JUnit 4
* Hamcrest
* Asserções
* Casos de teste
* Validação de resultados esperados
* Organização de testes
* Identificação de comportamentos esperados e inesperados
* Comentários Javadoc

## Tecnologias e ferramentas

* **Java 21**
* **JUnit 4.12**
* **Hamcrest Core 1.3**
* **Eclipse IDE**
* **Git**

## Testes unitários

Os testes foram desenvolvidos para validar o comportamento das funcionalidades da aplicação, comparando os resultados obtidos com os resultados esperados.

Com o **JUnit**, é possível estruturar e executar os casos de teste de forma automatizada.

O **Hamcrest** é utilizado como apoio às asserções, permitindo escrever verificações de forma mais expressiva.

## Principais aprendizados

Este projeto contribuiu para minha compreensão sobre a importância dos testes durante o desenvolvimento de software.

Entre os principais aprendizados estão:

* Como estruturar uma classe de testes;
* Como utilizar a anotação `@Test`;
* Como realizar asserções;
* Como verificar se um resultado corresponde ao comportamento esperado;
* Como organizar código de produção e código de testes;
* Como utilizar bibliotecas externas em um projeto Java sem Maven.
* Implementação de comentários Javadoc
